# ZYRO

**ZYRO** — Android-проект с собственной оболочкой для настроек и медиакомпонентов. Сейчас в репозитории есть две Android-библиотеки и самостоятельное demo-приложение, которое показывает, как подключать их к совместимому host-app.

> В репозитории нет исходников TikTok, его APK, ключей подписи, закрытых API или данных авторизации. ZYRO не внедряется в TikTok и не перепаковывает его APK.

## Что реализовано

### `zyro-settings`

- Экран настроек на Jetpack Compose, интерфейс на русском.
- Тёмная основа ZYRO, переключатель Liquid Glass.
- Параметры blur/transparency, интенсивности поверхностей, радиуса углов и силы анимаций.
- Системная, тёмная и светлая темы.
- Режим уменьшения движения.
- Пресеты акцента: фиолетовый, розовый, бирюзовый.
- Локальное сохранение через DataStore Preferences.
- Сброс настроек внешнего вида.

Важно: blur/transparency пока сохраняют предпочтения. Фактические визуальные эффекты должен отрисовать host-app.

### `zyro-camera`

- Диагностика Camera2: фронтальные, основные и внешние камеры, уровень Camera2, ориентация сенсора и вспышка.
- Поддерживаемые камерой размеры видеопотоков и AE FPS-диапазоны.
- High-speed режимы, EIS/OIS и динамические HDR-профили, если Android сообщает их.
- Выбор качества/FPS только из поддерживаемых камерой вариантов, сохранение выбора отдельно для каждой камеры.
- Выбор EIS/OIS/HDR с передачей параметров в host-app через callback.
- Управление зумом через CameraX ZoomControl и включение фонарика, если камера поддерживает вспышку.
- CameraX preview, переключение фронтальной/основной камеры и ручная запись видео.
- Запись запускается только после явного нажатия пользователя; имеется отдельная кнопка остановки.
- Запись без микрофона: модуль не запрашивает `RECORD_AUDIO`, не снимает в фоне и не отправляет файлы в сеть.
- На Android 10+ видео сохраняется в общей медиатеке `Movies/ZYRO` и появляется в галерее. На более старых Android файл хранится в приватной папке host-app `files/Movies/ZYRO`.

Доступность режима камеры не гарантирует идентичные FPS, обработку или качество после экспорта. Реальная комбинация потоков и ограничения устройства могут повлиять на результат.

### Creator Studio в `zyro-demo`

- Импорт видео через системный Android picker без запроса доступа ко всей галерее.
- Локальный предпросмотр через Media3 ExoPlayer с управлением воспроизведением и скоростью 0.5×–2×.
- Чтение имени, разрешения, длительности и размера выбранного файла.
- Системное меню «Поделиться» для передачи видео в совместимые приложения.
- Доступ к файлу сохраняется через persistable URI permission, пока пользователь не сбросит выбранный ролик.

Видео не отправляется на сервер и не загружается в TikTok автоматически. Это локальный creator-инструмент, а не встроенный редактор TikTok.

### `zyro-demo`

- Самостоятельное Android-приложение-хост с нижней навигацией.
- Открывает экран настроек, диагностику Camera2, отдельный экран ручной записи и Creator Studio для импорта/предпросмотра/передачи видео.
- Нужно для установки и проверки компонентов без подключения к TikTok.

**Demo APK не является модом TikTok.** Это отдельная тестовая оболочка и пример интеграции библиотек.

## Подключение библиотек к своему host-проекту

В Android Studio с JDK 17 и Android SDK Platform 36+ подключи модули. Камерный модуль и demo-приложение требуют Android 7.0 (API 24) или новее:

```kotlin
dependencies {
    implementation(project(":zyro-settings"))
    implementation(project(":zyro-camera"))
}
```

Экран настроек:

```kotlin
ZyroSettingsScreen(onClose = { /* закрыть экран */ })
```

Диагностика с передачей выбранных параметров:

```kotlin
ZyroCameraDiagnosticsScreen(
    onVideoSelectionChanged = { selection ->
        // Применить size и fps в собственном совместимом рекордере.
    },
    onAdvancedOptionsChanged = { options ->
        // Проверить и применить EIS/OIS/HDR к своей Camera2-сессии.
    }
)
```

Предпросмотр и ручная запись:

```kotlin
ZyroCameraRecorder(
    quality = ZyroVideoQuality.FULL_HD,
    onVideoSaved = { uri ->
        // Показать пользователю сохранённый файл и действие экспорта.
    },
    onError = { message ->
        // Показать ошибку.
    }
)
```

Модуль объявляет `android.permission.CAMERA`; host-app отвечает за runtime-разрешение. Аудио не записывается. На Android 10+ для сохранения в общую медиатеку дополнительное разрешение на хранилище не требуется.

## Сборка

В проекте пока нет Gradle Wrapper. При установленном Gradle 8.13:

```bash
gradle :zyro-settings:assembleDebug :zyro-settings:assembleRelease :zyro-camera:assembleDebug :zyro-camera:assembleRelease :zyro-camera:testDebugUnitTest :zyro-demo:assembleDebug
```

GitHub Actions выполняет эти задачи и публикует APK demo-приложения и AAR обеих библиотек как artifact `zyro-android-build`.

## Что ещё не готово

- Реальная интеграция с TikTok: исходный проект TikTok не предоставлен, загруженный XAPK является скомпилированным бинарным пакетом, а не исходным проектом.
- Физические тесты preview/recording на разных устройствах и версиях Android.
- Реальный Liquid Glass blur/transparency renderer.
- Английская локализация и полноценные экраны региона/языка.
- Подписанный production APK и опубликованный релиз.

ZYRO не обходит авторизацию, платежи, защиту аккаунтов, проверку целостности или региональные ограничения платформы.
